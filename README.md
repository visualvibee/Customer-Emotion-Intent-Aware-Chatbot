This project is an Emotion and Intent-Aware Customer Complaint Chatbot, built using RoBERTa.

The system detects both the emotional state and intent behind customer complaints, then uses that understanding to generate a more contextually appropriate response — not just a templated reply, but one that actually accounts for how the customer is feeling. I also built a custom fallback mechanism: if the model's confidence falls below a threshold, it either asks the customer a clarifying question or offers to transfer them to a human agent
